# Vehicle_Object_Detection_YOLO

A computer vision project using YOLOv8 to detect different types of vehicles from images.

## Project Overview

The model is trained to identify five vehicle classes:

* Ambulance
* Bus
* Car
* Motorcycle
* Truck

## Dataset

* 600+ annotated vehicle images
* Train, validation, and test datasets
* Dataset prepared in YOLO format using Roboflow

## Technologies

* Python
* YOLOv8
* OpenCV
* Roboflow
* Google Colab

## Model

A YOLOv8n model was trained for vehicle object detection and evaluated on validation and test data.

## Results

The trained model was tested on unseen images and generated bounding boxes, class labels, and confidence scores for detected vehicles.

## Project Workflow

Dataset Preparation → Annotation → YOLOv8 Training → Model Evaluation → Inference
